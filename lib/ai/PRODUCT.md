# AI Prompt 产品文档

> 本文档是 cc-videomind 项目 AI Prompt 的产品说明，定义每个 Prompt 的目的、成功标准和已知限制。

---

## 概览

| Prompt 文件 | 用途 | 输出格式 |
|-------------|------|----------|
| `prompts.ts` | V1 视频分析 + 对话 | JSON |
| `prompts-v2.ts` | V2 关键时刻 + 结构化摘要 | JSON |
| `prompts-learn.ts` | 学习功能（词义、翻译） | JSON / 索引文本 |

---

## 1. prompts.ts — V1 视频分析

### 产品定义

**解决什么问题？**
- 用户粘贴 YouTube 链接后，需要快速了解视频核心内容
- 需要结构化的学习笔记（摘要、要点、问题、高亮）

**为谁服务？**
- 英语学习者
- 视频内容研究者
- 需要快速掌握视频要点的用户

**拒绝什么？**
- 不生成与字幕无关的内容
- 不编造不存在的信息
- 不处理非视频内容

### 成功标准

| 指标 | 目标值 |
|------|--------|
| JSON 解析成功率 | > 95% |
| 字幕覆盖率 | > 80% 的关键内容 |
| 响应时间 | < 60s（单次调用） |
| 幻觉率 | < 5%（虚构内容） |

### 已知限制

1. **字幕长度限制**：最多处理 60,000 字符，超长视频会采样
2. **语言支持**：主要针对英文视频，中文视频效果可能较差
3. **上下文窗口**：受模型上下文长度限制，超长字幕会丢失细节

### Prompt 模板

```
系统角色：professional study notes assistant

输出格式：
{
  "summary": "2-3 句话摘要（100-200 字符）",
  "takeaways": ["5-8 个要点"],
  "suggestedQuestions": ["4-8 个问题"],
  "highlights": ["5-8 个高亮（含时间戳）"]
}

核心原则：
- 所有内容必须来自字幕
- 不得编造信息
- 优先提取：反直觉观点、核心论据、故事转折
```

## 2. prompts-v2.ts — V2 关键时刻 + 结构化摘要

### 产品定义

**解决什么问题？**
- 用户需要更精准的关键时刻提取
- 需要双语（中英文）输出
- 需要结构化的学习要点

**为谁服务？**
- 中英双语学习者
- 需要精确时间戳的研究者
- 教育内容创作者

**拒绝什么？**
- 不提取无关紧要的片段
- 不生成重复内容
- 不改变原始引用

### 成功标准

| 指标 | 目标值 |
|------|--------|
| JSON 解析成功率 | > 90% |
| 关键时刻准确率 | > 85% |
| 双语一致性 | > 90% |
| 时间戳准确率 | > 95% |

### 已知限制

1. **分块处理**：Fast 模式下每个块独立处理，可能遗漏跨块关联
2. **语言检测**：依赖字幕语言，混合语言效果可能较差
3. **主题过滤**：用户指定的主题可能影响提取质量

### Prompt 模板

```
系统角色：Video content analyst

输出格式：
{
  "moments": [
    {
      "title": "English title",
      "title_zh": "中文标题",
      "timestamp": "MM:SS-MM:SS",
      "quote": "English quote",
      "quote_zh": "中文引用",
      "reason": "English reason",
      "reason_zh": "中文原因"
    }
  ]
}

优先级：
1. 反直觉观点
2. 核心论据 + 数据
3. 故事转折点
4. 方法论

避免：
- 问候语和推广内容
- 无上下文的句子
- 重复内容
```

## 3. prompts-learn.ts — 学习功能

### 产品定义

**解决什么问题？**
- 用户在观看视频时遇到生词，需要快速查义
- 需要将字幕翻译成母语
- 需要双语对照学习

**为谁服务？**
- 英语学习者
- 需要翻译的非母语用户
- 语言教师

**拒绝什么？**
- 不翻译代码和 URL
- 不改变专有名词
- 不生成与上下文无关的翻译

### 成功标准

| 指标 | 目标值 |
|------|--------|
| 词义准确率 | > 95% |
| 翻译流畅度 | > 90% |
| 响应时间 | < 30s（30 词以内） |
| 格式一致性 | 100% |

### 已知限制

1. **批次限制**：每次最多 30 个单词
2. **上下文缺失**：词义生成不依赖视频上下文
3. **翻译质量**：依赖模型能力，可能有风格偏差

### Prompt 模板

#### 词义生成

```
系统角色：professional English lexicographer

输出格式：
{
  "definitions": [
    {
      "lemma": "word",
      "phonetic": "/IPA/",
      "partOfSpeech": "n./v./adj.",
      "definitionZh": "中文释义",
      "definitionEn": "English definition",
      "exampleEn": "Example sentence",
      "exampleZh": "中文例句"
    }
  ]
}

要求：
- 使用标准 IPA 音标
- 优先常见词义
- 例句自然地道
```

#### 字幕翻译

```
系统角色：Professional subtitle translator

输入格式：[INPUT_N]...[/INPUT_N]
输出格式：[OUTPUT_N]...[/OUTPUT_N]

原则：
- 翻译意思/意图，而非逐字直译
- 自然、流畅、地道
- 删除填充词/口误
- 修正语音识别错误
- 保留代码/URL/专有名词
```

## 4. 使用指南

### 如何修改 Prompt

1. **修改前**：先在本地测试，确保 JSON 解析正常
2. **修改后**：运行 `npm run test` 验证
3. **文档更新**：同步更新本文档的成功标准和已知限制

### 如何添加新 Prompt

1. 在对应文件中添加新函数
2. 更新本文档的概览表
3. 添加成功标准和已知限制
4. 编写测试用例

### 如何评估 Prompt 效果

1. **定量评估**：JSON 解析成功率、响应时间
2. **定性评估**：人工审查输出质量
3. **A/B 测试**：对比新旧版本效果
