# T10 真实设备与浏览器验收清单

状态：待执行。本清单要求在获准访问的候选环境执行；本地桌面浏览器结果不能替代以下实机结果。禁止使用真实用户账号、私密视频或付款信息。

## 统一准备

1. 使用独立访客会话或临时测试账号；记录环境标识和应用提交版本，不记录完整 URL、Cookie、账号或设备序列号。
2. 使用主持人预审的公开知识视频。测试一次成功路径，另一次模拟/实际可控失败路径；失败路径不得触发付费或无限重试。
3. 对每台设备执行：输入链接 → 解析 → 打开带时间点的字幕 → 保存 → 登录返回（适用时）→ 今日复习。另检查失败后输入保留、键盘焦点可见、只用触屏可完成、底部安全区不遮挡操作。
4. 若系统可设置，分别确认“减少动态效果”开启时没有阻塞性动画；将页面文字放大至系统常用最大档或浏览器 200% 后，主要路径仍可读可操作。

## 通过标准

- 没有水平滚动、被安全区/键盘遮挡的主操作、不可点击的关键控件或必须悬停才可发现的关键操作。
- 关键触屏目标不少于 44×44 CSS px；焦点状态清晰，表单与标签可由键盘或辅助技术辨识。
- 解析成功时可跳回正确字幕时间点；失败时有可理解恢复动作且不丢失已输入链接。
- 保存结果可在“今日复习”找到；登录返回不把学习正文放进 URL。
- 每条不通过项必须有脱敏问题代码和复现步骤；不得以“未测”标为通过。
