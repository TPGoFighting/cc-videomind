# T04/T05 五位目标用户验证方案

状态：待执行。此文件是现场记录模板，不代表任何真实用户测试已完成。

## 目的与边界

验证中文英语学习者能否在不被引导的情况下理解 Teach Player 的价值，并在 10 分钟内完成一次首次保存。只记录匿名编号和任务结果；不记录姓名、邮箱、账号、密码、视频链接、字幕、录屏原文件或自由文本学习内容。

招募 5 位非团队成员：以中文为主要界面语言、每周至少观看一次知识型 YouTube 视频、正在学习英语。测试前取得参与同意；参与者可随时跳过问题或退出。每人使用独立浏览器访客会话；如需验证登录续存，由主持人提供临时测试账号，参与者不输入自己的账号。

## 每位参与者流程（15–20 分钟）

1. 分配 `P01` 至 `P05` 匿名编号，清空浏览器站点数据并打开已获准的候选环境首页。
2. 静默展示首页 10 秒，不解释产品。请参与者回答：
   - “这是什么产品？”
   - “粘贴视频后会得到什么？”
   - “为什么值得明天回来？”
3. 给出任务卡：使用主持人预审的公开、非敏感知识视频，完成“粘贴链接 → 获取字幕/结果 → 打开一个带时间点的内容 → 保存一个词、句子或观点”。不得让参与者输入私密视频、私人笔记或支付信息。
4. 如保存触发登录，使用临时测试账号完成“登录/注册 → 返回原视频 → 自动续存”。记录是否回到正确页面，不记录凭证。
5. 让参与者完成“进入今日复习并说出下次行动”，再询问一个简短开放题：最大困惑是什么？主持人仅将其归纳为预定义问题代码，不记录原话。
6. 结束后退出临时账号、删除该次浏览器站点数据；测试账号数据按隐私验收方案处理。

## 结果判定

- 10 秒理解通过：回答覆盖产品对象、粘贴后的双语/可核验学习材料、以及保存后复习/明日回访三个要点。
- 首十分钟通过：从开始任务到首次保存不超过 10 分钟；字幕或解析失败时，已输入链接仍在且参与者能找到恢复动作。
- 不把主持人提示后的成功算作无辅助成功；提示只可记录为 `H1`（轻提示）或 `H2`（主持人操作）。
- 只有 5 位全部完成并留下表格证据，才能关闭 T04/T04A/T05 对应的真实用户门禁；任何失败先归类并修复后重测，不用平均分掩盖阻断问题。
