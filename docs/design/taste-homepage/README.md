# Teach Player Taste 首页实验

## 目标

把首页从偏装饰性的 3D 科技展示页，收敛为面向个人学习者的“深夜编辑式学习工作台”。首屏只回答三件事：产品是什么、粘贴视频后得到什么、为什么值得第二天回来。

## 视觉方向

- 背景：冷调墨黑 `#080B0F`
- 表面：`#0C131C`、`#111A25`
- 主文字：`#F4F7FA`
- 次文字：`#9AA8B7`
- 唯一强调色：冰蓝 `#5BA8FF`
- 版式：12 列编辑式分栏，桌面首屏 5/7，移动单列
- 标题：桌面固定两行，移动最多三行
- 容器：细边框、克制圆角，不使用默认三卡片或大面积玻璃容器
- 字体：Satoshi 负责英文与数字，中文回退到系统黑体
- 动效：首屏渐入、能力连续带、证据标题固定、逐词滚动揭示与证据面板层叠；尊重 `prefers-reduced-motion`

## 页面结构

1. 首屏：真实 URL 输入 + 可操作工作区预览
2. 学习闭环：粘贴视频 → 对照字幕 → 保存并复习
3. 可信证据：字幕、时间戳、引用问答和复习队列
4. 学习场景轮播：英文访谈、技术课程与演讲复盘，不伪造用户评价
5. 最终行动：回到同一个视频输入

## 实现偏差记录

| 项目 | 概念图 | 实现 | 原因 |
| --- | --- | --- | --- |
| Logo | 生成的蓝色三角标 | 保留现有 Teach Player Logo | 不擅自更换品牌资产 |
| 视频画面 | 生成式讲师画面 | 使用现有公开视频缩略图 | 避免伪造产品媒体 |
| 移动导航 | 概念中的汉堡入口 | 保留现有底部导航和登录入口 | 保留已有功能与路径 |
| 页脚政策 | 可点击链接 | 显示为待完善文本 | 仓库暂无真实政策页面，避免死链 |
| 动效 | 静态概念提示 | GSAP 渐入与层叠，支持减弱动态 | 使用项目现有依赖并满足可访问性 |

## 验收基线

- 桌面：1440×900
- 平板：1024×900
- 移动：390×844
- 页面无水平溢出
- 可见交互目标不小于 44px
- URL 输入、字幕/摘要/复习标签可操作
- 浏览器控制台无相关 error 或 warning
- 自动化视觉检查不得调用真实 AI、支付或生产用户数据
